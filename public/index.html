Arsitektur & Cara Kerja Sistem

Inovasi kontrol iklim otomatis berbasis mikrokontroler modern

01

Sensor Presisi (DHT22)

Mengambil data suhu dan kelembapan real-time secara berkala di dalam ruangan berukuran 15 m².

02

Cloud Sync (Supabase)

Menghubungkan mikrokontroler ESP32-S3 ke database awan untuk sinkronisasi perintah dan telemetri energi.

03

Eksekusi IR Daikin128

Memancarkan sinyal inframerah kustom secara otomatis menyesuaikan kondisi termal atau input web.

04

Open-Meteo Integration

Membaca parameter cuaca luar ruangan di wilayah Surakarta untuk mode penyesuaian suhu adaptif.
